LapsTool 0.1.0-alpha を公開しました。

Active Directory の LAPS で管理されているローカル管理者パスワードを参照し、**有効期限の変更**と、**参照したパスワードでのリモートデスクトップ接続**までを1つの画面で行える Windows 用 GUI ツールです。ローカル管理者権限なしで動きます。

---

## できること

- **パスワードの参照**：コンピューター名で検索し（`*` でワイルドカード）、パスワードを取得します。表示は伏せ字が初期状態で、［表示］で平文に切り替わります。コピーしたパスワードは、一定時間（初期値30秒）が過ぎるとクリップボードから自動で消去します
- **Windows LAPS と旧 LAPS の両方に対応**：どちらで管理されている端末かは自動で判定します。Windows LAPS（暗号化パスワードを含む）は Microsoft 公式の `LAPS` PowerShell モジュールで取得し、旧 Microsoft LAPS は `ms-Mcs-AdmPwd` 属性を読みます
- **有効期限の変更**：日時を指定して変更するか、今すぐ期限切れにできます。パスワードが実際に変わるのは、対象端末で次にポリシーが処理されたときです
- **リモートデスクトップ接続**：パスワードを入力・貼り付けせずに接続できます。資格情報を「このログオン中のみ」有効な形で一時登録して mstsc に渡し、接続後（初期値20秒後）とツールの終了時に削除します
- **接続に使うローカルアカウント名を設定可能**：会社ごとに異なるアカウント名に合わせられます。Windows LAPS が記録しているアカウント名を優先することもできます
- **会社ごとの初期値を配布可能**：設定画面から `LapsTool.defaults.xml` を書き出し、exe と同じフォルダに置くと、全利用者の初期値になります
- **操作ログ**：誰が・いつ・どの端末を参照・変更したかを記録します。パスワードは記録しません

## 権限について

本ツールは**サインインしているユーザーの権限**で AD にアクセスします。誰がパスワードを参照・変更できるかは AD と LAPS の権限設定で決まり、本ツールがそれを迂回することはありません。必要な権限は README を参照してください。

パスワードの扱いの詳細は [SECURITY.md](../../blob/main/SECURITY.md) にまとめています。

LapsTool 0.1.0-alpha is the first public release.

LapsTool is a small Windows GUI that looks up local administrator passwords managed by LAPS in Active
Directory, changes their expiration time, and opens a Remote Desktop session with the retrieved
password - all from one window, without local admin rights.

- **Windows LAPS** (encrypted or clear-text, via Microsoft's `LAPS` PowerShell module) and **legacy
  Microsoft LAPS** (`ms-Mcs-AdmPwd`) are both supported and detected per computer
- **Remote Desktop without typing the password**: the credential is stored for the current logon
  session only, handed to mstsc, and deleted after a short delay (20 seconds by default) and when the
  tool exits
- **The local account name used for connections is configurable**, and organization-wide defaults can
  be shipped as `LapsTool.defaults.xml` next to the executable
- Copied passwords are cleared from the clipboard automatically; an operation log records who viewed
  or changed what, never the password itself
- All authorization is left to Active Directory. See SECURITY.md for how passwords are handled

**Status**: tested with legacy LAPS. **Windows LAPS has not been tested yet** - reports in Issues are
welcome. The UI and documentation are in Japanese.

Unofficial tool, not affiliated with Microsoft. Binaries are not code-signed.
